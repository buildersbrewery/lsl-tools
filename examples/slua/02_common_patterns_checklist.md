# SLua — Common Patterns Checklist (Complementary)

Use this as a light checklist while practicing.  
It is **not** a class curriculum.

### Fundamentals worth being comfortable with
- [ ] How a basic script is structured
- [ ] Defining and calling functions
- [ ] Working with tables (the main data structure)
- [ ] Responding to touch / common world events
- [ ] Simple chat or owner feedback
- [ ] Basic error awareness

### Habits that transfer well from good LSL practice
- [ ] Clear naming
- [ ] Small, focused pieces of logic
- [ ] Explicit permissions handling where needed
- [ ] Testing in-world frequently instead of writing large untested blocks
- [ ] Reading official documentation when something is unclear

### When you get stuck
1. Check the current official SLua documentation.
2. Review any notes from the Builders Brewery classes you are taking.
3. Ask in the appropriate BB class or study channels.
4. Only then look for supplemental public examples.

These public patterns exist to support practice, not to replace guided instruction.
