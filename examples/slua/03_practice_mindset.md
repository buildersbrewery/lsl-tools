# SLua — Practice Mindset (Complementary)

These notes support self-practice only.  
They are not a class outline and do not replace Builders Brewery SLua instruction.

## Helpful habits while learning SLua

- Keep experiments small. Change one thing, test in-world, then continue.
- Read error messages carefully; they are usually trying to help.
- Prefer clear names and short functions over clever one-liners.
- When something works, save a clean copy before you experiment further.
- Return to official documentation when behavior surprises you.

## Relationship to live classes

If you are enrolled in a Builders Brewery SLua series:

1. Let the class set the main sequence and depth.
2. Use public examples only for light extra practice.
3. Bring real questions back to the instructors and study sessions.

If you are waiting for the next series:

- Strengthen your LSL fundamentals (events, communications, Linkset Data).
- Review the light awareness notes in this folder.
- Join the next available BB SLua classes when they open.

Good fundamentals + guided instruction remain the strongest path.
