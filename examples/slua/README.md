# SLua Patterns & Notes

**These materials are complementary only.**

Builders Brewery runs structured SLua classes (Basics, Advanced, and study groups).  
Those live classes, and the materials prepared by the instructors, are the primary teaching resource.

The files in this folder provide:

- General syntax awareness
- Simple reusable patterns
- Notes that help LSL scripters prepare for SLua

They are **not** a substitute for attending the classes or for the instructors’ own content.

When SLua syntax or available libraries change (it is still evolving), these examples should be reviewed and updated. Prefer official Linden Lab documentation for authoritative details.
