# Sandbox Challenges

Little missions. Not homework. Not a class.

Rez a box in the **Builders Brewery Sandbox**, start from a practice script, and see if you can do these.

## Warm-ups
1. Change the hello message so it includes the day of the week... or just something sillier.
2. Make the color toggle cycle through three colors.
3. Make the counter reset when the owner says `/5 reset`.

## Stretch a little
4. Combine listen + hover text: the object displays the last thing someone said to it.
5. Greet people with the sensor, but only once every 20 seconds (no spam).
6. Use a table as a tiny config: store `channel`, `range`, and `greeting` in one table.

## Bring it to study group
If you get it working, great. If you get a weird error, even better.
Bring the object or the error text to study group, class, or Discord.

The circle: try it, break it, ask, try again.
