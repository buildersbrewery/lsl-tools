# Recipe cards

One job. One short script. Copy, rez, tweak.

Not class packets. If your teacher handed you a different door, use theirs.

| File | Language | Job |
|---|---|---|
| `door_toggle.lsl` | LSL | Touch to swing a door |
| `door_toggle.luau` | SLua | Same door |
| `light_toggle.lsl` | LSL | Touch to dim / undim |
| `light_toggle.luau` | SLua | Same light |
| `anti_spam_touch.lsl` | LSL | Ignore frantic clicking |
| `anti_spam_touch.luau` | SLua | Same cooldown |
| `give_item.lsl` | LSL | Touch to hand someone a copy of `Gift` |
| `give_item.luau` | SLua | Same gift |
| `config_from_desc.lsl` | LSL | Read a setting from the object description |

Dropdown: `.lsl` files need an **LSL:** compiler. `.luau` files need **Lua**.
