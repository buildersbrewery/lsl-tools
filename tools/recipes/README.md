# Script Recipe Cards

One problem. One short recipe. Copy, rez, tweak.

These are public practice recipes, not teacher class packets.

| Recipe | Language | Use |
|--------|----------|-----|
| `door_toggle.lsl` | LSL | Touch to open/close a simple door rotation |
| `config_from_desc.lsl` | LSL | Read a setting from the object description |
| `anti_spam_touch.lsl` | LSL | Ignore rapid repeat touches |
