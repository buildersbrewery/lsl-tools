# Priority Topics

Last updated: August 2026

This list guides what we add next. It is not a class schedule.

We look at:

- What residents ask for
- Skills you need to make almost anything
- Platform changes already in motion (SLua first)

## Priority 1 — Now

| Topic | Why |
|-------|-----|
| **SLua basics** | The big shift. Practice in the BB Sandbox. Classes still come first. |
| **Linkset Data** | Modern storage. Beats a lot of old workarounds. |
| **PBR / glTF awareness** | Scripts meet modern materials. |
| **Experiences** | Still the right tool for many avatar-specific permissions. |

## Priority 2 — Always needed

Events and flow. Chat, listen, dialogs, link messages. HTTP. Notecards and inventory. Basic permissions.

## Priority 3 — When you're ready

Performance. JSON. Pathfinding. Combat 2.0. Multi-script layout.

## Priority 4 — Later branches

Animation, vehicles, shared media, reading error messages, and the rest of content creation (textures, environments) once the scripting bench is solid.

## How we keep this honest

Official Linden changes jump the line.  
Teacher feedback and class calendar matter more than a clever idea.  
If an example fights a live class, we change the example.
