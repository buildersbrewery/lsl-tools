# Quick Guide for Teachers and Students

This repository is a **complementary toolkit**. It supports the live classes at Builders Brewery; it does not replace them.

## For Students

**If you are taking a BB class right now**
- Use the examples here for extra practice between sessions.
- When something is unclear, bring the question to class or to the appropriate study channel.
- The live instructor materials and explanations always take priority.

**If you cannot attend live classes**
- Start with the Beginner examples and work upward.
- Read `docs/PRIORITY_TOPICS.md` to see what skills matter most right now.
- When SLua classes are running, consider joining them — the structured teaching is the best way to learn it properly.

**Suggested path**
1. Beginner examples → get comfortable with events, touch, timer, listen, simple dialogs.
2. Intermediate examples → communications, notecards, Linkset Data, HTTP.
3. Advanced examples → modern patterns and readiness notes.
4. SLua folder → light complementary awareness only.

## For Teachers

- You are welcome (but never required) to point students at specific public examples.
- Nothing here is intended to reproduce your lesson plans, exercises, or unique explanations.
- If you see a gap that would help students between classes, opening a GitHub issue or note is welcome.
- The `docs/COMPLEMENTARY_TO_CLASSES.md` document is the standing rule for all contributors.
