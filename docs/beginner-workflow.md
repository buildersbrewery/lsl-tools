# Recommended Beginner Workflow

This is a simple path that has worked for many new scripters at Builders Brewery.

## 1. Start with the examples

Open the scripts in `examples/beginner/` one at a time.

- Read the comment block at the top.
- Copy the script into a new prim or inventory script.
- Save and test the behavior in-world.
- Change one small thing (the message text, the sensor range, the timer interval) and observe the result.

## 2. Learn the core events early

Most beginner scripts revolve around a small set of events:

- `state_entry`
- `touch_start` / `touch` / `touch_end`
- `timer`
- `sensor` / `no_sensor`
- `listen`

Master these before moving to HTTP, experiences, or linkset data.

## 3. Use the tools

- Syntax highlighting and completions reduce typing errors.
- Tooltips (when available) give you a quick reminder of what a function expects.
- Keep the official Second Life wiki LSL Portal open in a browser tab for deeper reading.

## 4. Progress deliberately

When a beginner script feels comfortable:

- Move to the intermediate examples (dialogs, basic communication patterns).
- Then look at the advanced examples for modern features.

## 5. Ask for help the productive way

When something doesn’t work:

1. Note the exact error message (if any).
2. Note what you expected vs what happened.
3. Share the smallest script that shows the problem.
4. Say what you have already tried.

The Builders Brewery community and teachers respond best to clear, specific questions.
