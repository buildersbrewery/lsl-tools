# How These Tools Complement (Never Replace) Builders Brewery Classes

**Important principle**

The materials in this GitHub repository are designed to **add value** to the teaching already happening at Builders Brewery. They must never compete with, copy, or diminish the live classes or the instructors’ own prepared materials.

## What this repository is

- Free, public, self-serve example scripts and reference patterns
- A permanent place students can return to for quick reminders and practice
- A resource that works even when someone cannot attend a live class
- A support tool that teachers may optionally point students toward

## What this repository is not

- A replacement for live instruction
- A copy of any teacher’s class notes, lesson plans, or proprietary materials
- A full curriculum that tries to reproduce the multi-week SLua or LSL series

## Protection of instructor work

- All class materials created by BB teachers remain their intellectual property.
- Nothing in this repository is intended to reproduce the structure, sequence, exercises, or unique explanations used in live classes.
- When students ask deep or class-specific questions, the correct response is still to attend the classes or ask the instructors.
- Teachers are encouraged (but never required) to reference these public examples if they find them helpful.

## Recommended use

| Audience | Suggested use of this repo |
|----------|----------------------------|
| Students attending BB classes | Extra practice patterns and quick reference between sessions |
| People who cannot attend live | Foundational examples and modern patterns while they wait for the next class series |
| Teachers | Optional supplemental examples; never a substitute for their own materials |
| Self-learners outside BB | Clear, honest starting points that also encourage them to discover Builders Brewery classes |

## SLua specifically

Builders Brewery has been teaching SLua for months and will continue structured classes (including the series restarting in September).  

The SLua-related files here are general syntax patterns and readiness notes only. They exist to support practice and awareness, not to replace the carefully prepared live instruction.
