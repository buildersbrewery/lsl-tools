# GitHub for Second Life Creators

GitHub is not only for professional programmers. It is a public workshop bench.

## What it is good for at Builders Brewery

- Keeping example scripts in one place so they do not vanish from inventory
- Sharing versions: "this is the latest," not "which notecard is the good one?"
- Letting teachers point students at a stable URL
- Accepting suggestions without rewriting the whole world
- Showing the rest of SL that BB still builds tools for the community

## Uses we have barely started

1. **Versioned example packs** — tag a release when a class series starts
2. **Issue tracker as a help desk** — "this example broke after the last SLua change"
3. **Discussions** — longer than Discord, searchable later
4. **Project boards** — what we want to add next
5. **Pages / simple website** from the repo README
6. **Gists or extra repos** later for animation, PBR, textures, environments

## What GitHub is not

- A replacement for live classes
- A dump of teacher-owned class packets
- A place to publish private resident data

## Student-friendly first step

1. Make a free GitHub account.
2. Open https://github.com/buildersbrewery/lsl-tools
3. Copy one example.
4. Rez it in the BB Sandbox.
5. Change one line. Smile or scream. Repeat.
