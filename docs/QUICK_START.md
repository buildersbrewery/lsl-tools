# Quick start

Five minutes. One prim. Then go outside or come back to class.

## LSL

1. Open [`examples/beginner/01_hello_touch.lsl`](../examples/beginner/01_hello_touch.lsl).
2. In the viewer, compiler dropdown: any **LSL:** option (Mono is fine).
3. Paste, save, touch the prim.
4. Keep walking through `examples/beginner/` in order.

## SLua

1. Open [`examples/slua/01_hello_touch.luau`](../examples/slua/01_hello_touch.luau).
2. Compiler dropdown: **Lua**.
3. Paste, save, touch the prim.
4. If it will not save, read [`SLUA_GOTCHAS.md`](SLUA_GOTCHAS.md) before rewriting the whole thing.

Best place to test: the Builders Brewery Sandbox (SLua-enabled).

Classes still come first. This folder is the homework table in the hallway.
