# Quick Start

Welcome. This repository gives you free, practical LSL (and complementary SLua) examples and tools.

## New to scripting?

1. Open the folder `examples/beginner/`
2. Start with `01_hello_touch.lsl`
3. Copy the script into a prim in Second Life, save, and test
4. Work through the beginner examples in order

## Taking a Builders Brewery class?

These examples are **extra practice only**.  
Your instructor’s materials and the live class always come first.  
See `docs/COMPLEMENTARY_TO_CLASSES.md` and `docs/FOR_TEACHERS_AND_STUDENTS.md`.

## Want modern / advanced patterns?

- Look in `examples/intermediate/` and `examples/advanced/`
- Especially useful: Linkset Data, clean link messages, experiences, sensors

## Interested in SLua?

- See the light notes in `examples/slua/`
- For proper learning, join the Builders Brewery SLua classes when they are running
