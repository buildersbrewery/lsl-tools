# Archive Notes — Previous Builders Brewery LSL Repositories

The following repositories under the `buildersbrewery` GitHub organization are considered historical and are no longer the active source of tooling:

- `buildersbrewery/sublime-lsl` (last meaningful activity ~May 2020)
- `buildersbrewery/linden-scripting-language` (~2020)
- Earlier forks / copies of language definition files

## Recommended Archive Actions (to be performed by a GitHub organization owner)

1. Rename the old repositories for clarity, for example:
   - `sublime-lsl` → `sublime-lsl-archive-2020`
   - `linden-scripting-language` → `linden-scripting-language-archive`

2. Add a clear banner / note at the top of each archived README:

   > **This repository is archived and no longer maintained.**  
   > Current Builders Brewery LSL tools live at: [link to new repo]

3. Optionally transfer or mirror them to a separate “archive” organization if desired.

4. Update any external links (Builders Brewery website, Discord pins, in-world notecards, wiki pages) to point to the new active repository.

The new active project begins with a clean structure focused on current Second Life language features and on serving scripters of every experience level.
